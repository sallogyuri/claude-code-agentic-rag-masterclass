# Module 5: Multi-Format Document Support (Docling)

## Context

Currently the ingestion pipeline only supports plain text via `file_bytes.decode("utf-8")` (ingest.py:25). The frontend restricts uploads to `.txt` and `.md`. Module 5 adds PDF, DOCX, and HTML support using Docling — IBM's document parsing library — with no other parsers.

No DB schema changes are needed. Cascade deletes already exist in migrations 002–004.

## Step 2 — `backend/services/parsing_service.py` (new)

```python
import os
import tempfile

_TEXT_EXTENSIONS = {".txt", ".md"}
_DOCLING_EXTENSIONS = {".pdf", ".docx", ".html"}


def extract_text(file_bytes: bytes, filename: str) -> str:
    ext = _get_extension(filename)
    if ext in _TEXT_EXTENSIONS:
        return file_bytes.decode("utf-8")
    if ext in _DOCLING_EXTENSIONS:
        return _docling_extract(file_bytes, ext)
    try:
        return file_bytes.decode("utf-8")
    except UnicodeDecodeError as exc:
        raise ValueError(f"Unsupported file type '{ext}' and content is not valid UTF-8.") from exc


def _get_extension(filename: str) -> str:
    _, ext = os.path.splitext(filename)
    return ext.lower()


def _docling_extract(file_bytes: bytes, ext: str) -> str:
    from docling.document_converter import DocumentConverter  # deferred — keeps tests fast

    tmp_path = None
    try:
        with tempfile.NamedTemporaryFile(suffix=ext, delete=False) as tmp:
            tmp.write(file_bytes)
            tmp_path = tmp.name
        # File closed before Docling opens it — required on Windows
        converter = DocumentConverter()
        result = converter.convert(tmp_path)
        return result.document.export_to_markdown()
    finally:
        if tmp_path and os.path.exists(tmp_path):
            os.unlink(tmp_path)
```

Key design choices:
- **Deferred import** — `DocumentConverter` imported inside `_docling_extract`, not at module top-level. Keeps tests fast and isolates Docling.
- **`delete=False` + `finally: os.unlink`** — Windows exclusive lock pattern. NamedTemporaryFile on Windows can't be opened by another process while Python holds it open.
- **Fallback** — unknown extensions attempt UTF-8 decode, preserving prior behaviour.

## Step 4 — `backend/tests/test_parsing_service.py` (new)

8 tests covering:
1. `.txt` → UTF-8 passthrough
2. `.md` → UTF-8 passthrough
3. `.txt` does NOT invoke Docling
4. `.pdf` routes to `_docling_extract`
5. `.docx` routes to `_docling_extract`
6. `.html` routes to `_docling_extract`
7. Unknown extension + valid UTF-8 → fallback decode
8. Unknown extension + binary → `ValueError`

Docling is mocked via `unittest.mock.patch("services.parsing_service._docling_extract")` for routing tests, and `sys.modules` injection for the deferred import inside `_docling_extract` itself.

No `conftest.py` changes needed — Docling is not imported at app startup.
